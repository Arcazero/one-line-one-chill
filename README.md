One original sentence of horror (114 characters) that has to frighten a reader in one breath — an entry for make.fun's "One Line, One Chill" bounty ($5 in USDC).

## The line

> The rescue team found my tent zipped from the inside, my journal's last page reading: 'It learned my voice today.'

114 characters, one sentence. The full line also lives in `entry.txt`.

## Run it

```sh
python3 main.py
```

`main.py` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), which is what the bounty judge reads. No network, no dependencies, deterministic.
